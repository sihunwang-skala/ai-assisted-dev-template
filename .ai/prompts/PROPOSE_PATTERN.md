# Prompt: Assess an Optional Engineering Pattern

Current project: [name]
Task: [one sentence]
Candidate pattern: [e.g. `.ai/patterns/multi-agent.md`]

1. Read `AGENTS.md`, relevant approved requirements and baseline, then ONLY the candidate pattern.
2. State whether existing architecture already solves the need. Compare at least the simplest adequate alternative.
3. Give a concise table: existing approach / proposed pattern / measurable benefit / cost (latency, tokens, infra, complexity) / risks / test criteria.
4. If the pattern changes Architecture, Product behavior, API/DB/permissions, UX policy or monetary costs: **do not implement now**. Ask me explicitly whether to adopt it.
5. If not useful, recommend keeping current solution; do not expand the scope or generate boilerplate.
