## Consistency guardrail
- 무작위 그라데이션, 의미 없는 카드 쌓기, 과도한 뱃지/이모지, 지나친 장식, 획일적 마케팅 문구를 기본 패턴으로 쓰지 않는다.
- 사용자 목적과 브랜드 톤에 맞는 Design Tokens와 재사용 가능한 컴포넌트를 먼저 정의한다.
- 이미 승인된 UI 흐름, 카피, 이름, 레이아웃 변경은 변경안과 시각적 전후 차이를 보여주고 승인받는다.
- 폰트/이미지/아이콘은 라이선스 및 외부 의존성 확인 후 사용한다.
- 스크린샷 비교는 승인된 기준 이미지가 있는 경우에만 의미 있다. 의도된 변화와 Regression을 구분한다.
