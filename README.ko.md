# AI 지원 개발 템플릿 (개발템플릿)

[English](README.md) | **한국어**

**목적:** Claude Code, Codex 같은 AI 코딩 에이전트가 **웹/모바일 백엔드, 프런트엔드, Python/데이터 도구, (선택) LLM/Agent 서비스**를 안전하게 만들 수 있도록 돕는, 특정 서비스에 묶이지 않은 재사용 저장소 템플릿입니다. 만든 앱이 반드시 AI를 써야 한다는 뜻은 아닙니다.

**상태:** v1.11. 문서와 엔지니어링 지침만 있습니다. 애플리케이션 코드, 환경 구성, 필수 오케스트레이션, 활성 CI는 없습니다. (`.ai/kits/` 아래 파일은 복사용 원본이며 설치되어 있지 않습니다.)

## 새 프로젝트 시작
1. 이 템플릿을 **새 프로젝트마다 한 번만** 새 폴더로 복사합니다. 작업마다 다시 복사하지 말고, 템플릿 안에서 직접 앱을 개발하지 않습니다.
2. `docs/PROJECT.md`에 제품 목표, 시간/비용 예산, 선택한 스택을 적습니다. 모르는 항목은 미승인으로 남깁니다.
3. `docs/REQUIREMENTS.md`(승인된 기능과 인수 조건), `docs/BASELINE.md`(관찰 가능한 기준선), `docs/DECISIONS.md`(결정 기록)를 채웁니다.
4. Claude Code나 Codex에 `.ai/prompts/START.md`를 주고, 가장 작은 Vertical Slice를 요청한 뒤 동의 하에 구현합니다.
5. 반복: 범위 한정 변경 → 테스트 → diff 검토 → 결정 기록 → 승인된 병합.

## 기존 프로젝트에 적용
`.ai/prompts/ADOPT_EXISTING.md`를 사용합니다. **기존 AGENTS/CLAUDE, 요구사항, 검증된 코드, 설정을 덮어쓰지 않고** 먼저 비교/병합 계획을 만듭니다.

## 구성
| 경로 | 역할 | 로드 시점 |
|---|---|---|
| `AGENTS.md` / `CLAUDE.md` | 짧은 공통 에이전트 규칙, 승인 경계, diff/테스트 원칙 | 항상 |
| `docs/PROJECT.md`, `REQUIREMENTS.md`, `BASELINE.md`, `DECISIONS.md` | 프로젝트별 단일 진실 원천 | 작업에 따라 |
| `.ai/ROUTER.md` | 필요한 가이드/패턴만 고르는 라우터 | 필요할 때만 |
| `.ai/guides/` | 레이어별 엔지니어링 가이드 | 해당 레이어만 |
| `.ai/PATTERN_CATALOG.md`, `.ai/patterns/` | **선택형 구현 패턴 37개** | 선택한 패턴만 |
| `.ai/kits/secret-scan/` | 선택형 Gitleaks 시크릿 유출 방지 키트 (Actions, pre-push Hook, 로컬 테스트, 설치/사고 대응) | 승인 후 설치 |
| `.ai/prompts/` | 시작, 기능, 버그, 리뷰, 인수인계, 기존 프로젝트 적용, 패턴 제안 | 해당 워크플로 |
| `docs/APPROVAL_POLICY.md` | 명시적 승인이 필요한 변경 | 변경 제안 시 |
| `docs/ENFORCEMENT_MATRIX.md` | 중요한 규칙 ↔ 검사/증거/실패 동작 연결 | 게이트 선택, 위험 검토 시 |

## 핵심 원칙
- **선택적 컨텍스트 로딩:** 요청과 관련 코드/테스트/diff에서 시작합니다. 모든 `.md`를 매번 읽지 않습니다.
- **승인 경계:** 동작, 아키텍처, API, DB, 보안, UX, 비용 변경은 승인 후에 합니다. `.md` 파일이 있다는 이유만으로 패턴이 자동 적용되지 않습니다.
- **측정 우선:** 고급 패턴(멀티 에이전트, Kubernetes, MSA, Rust 이전 등)은 기본값이 아니며, 측정 가능한 근거가 있을 때만 제안합니다.
- **규칙은 강제가 아닙니다:** 지침은 준수를 증명하지 않습니다. 위험에 비례해 테스트, CI, Hook 같은 결정론적 검사를 추가합니다. 실행하지 않은 테스트를 통과했다고 말하지 않습니다.

## 선택 패턴 예시
- **Multi-Agent:** 기능 요청 → 단일 호출/고정 워크플로/단일 Agent 기준선 평가 → 정말 이점이 있을 때만 `.ai/patterns/multi-agent.md`를 열어 호출 수, 지연, 비용, 위험, 테스트를 포함해 **제안** → **사용자 승인 후** 구조 변경.
- **Rust 병목 이전 (`.ai/patterns/rust-hotspot.md`):** 전체를 Rust로 다시 쓰지 않습니다. 대표 작업을 프로파일링해 CPU-bound 병목을 찾고, 알고리즘/캐시/기존 native 라이브러리를 먼저 시도한 뒤, 그래도 부족한 한두 함수만 승인 후 이전합니다. 언어 경계 변환 비용을 포함한 전체 실행 시간을 전후 비교하고, 이득이 없으면 되돌립니다. 외부 사례의 배수(예: "116배")는 근거로 쓰지 않습니다.
- **시크릿 스캔 (`.ai/kits/secret-scan/`):** 로컬 pre-push Hook → GitHub Push Protection → Actions(현재 파일 + 전체 이력) → Ruleset 필수 검사. 실제 키 없이 가짜 토큰으로 탐지를 검증합니다.

## 안전 메모
실제 자격 증명, 고객 데이터, 저작권이 있는 교재 원문, 비공개 채팅 로그를 커밋하지 마세요. 이 저장소의 지침은 일반적인 엔지니어링 규칙이며 테스트와 코드 리뷰를 대체하지 않습니다.

공개 저장소는 로컬 마스터에서 템플릿 관리 전용 폴더(`_master/`)를 제외한 미러입니다.
